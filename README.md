# 野電計畫 WildVolt

以「露營、車露、爬山」為主軸的台灣行程規劃網頁。從挑選營地／登山口開始，串成路線、估算 2024 Luxgen n⁷ 短程版的電量與補電點，最後找出營地周邊可以吃什麼。

純前端（vanilla JS + Leaflet），沒有建置流程，資料為示範用途。

---

## 快速開始

```powershell
cd wildvolt
node ../tools/serve.mjs
# http://127.0.0.1:4173/
```

建議用本機伺服器開啟：直接雙擊 `index.html`（file://）雖然看得到畫面，但「取得道路里程」與「OSM 即時搜尋」會被瀏覽器的 CORS 規則阻擋。

需要網路連線載入：Leaflet、MarkerCluster、Google Fonts、圖磚（一般圖層為 OSM 法國 HOT、地形圖層為 Esri World Topo；不要再用 tile.openstreetmap.org，官方圖磚伺服器會回傳 Access blocked 圖磚）。本機檔案本身可離線開 App 殼（PWA Service Worker），但地圖圖磚與 OSRM／Nominatim 即時查詢仍需網路。

## 四個分頁

| 分頁 | 用途 |
| --- | --- |
| **探索** | 依類別（露營 17／車露 12／登山 20／美食 54）、區域、關鍵字與排序瀏覽示範據點；點選據點可在右側地圖檢視詳細卡、加入行程或找附近美食。 |
| **行程** | 設定出發地（含瀏覽器定位）、載入範例行程、加入／排序／移除站點；顯示每段里程、爬升、抵達電量與補電建議，可向 OSRM 取得實際道路里程。 |
| **電動車** | 選擇 n⁷ 車型或自訂，調整電池容量、滿電里程、出發電量、保留電量、氣溫、空調、載重、路況與天候；地圖同步畫出以出發地為圓心的可用里程圈。 |
| **美食** | 以行程站點或任一營地／車泊點／登山口為圓心，依半徑與類型找附近店家；先用內建 54 筆資料，按「OSM 即時搜尋」可補上 OpenStreetMap 的即時店家。 |

其他功能：

- 行程可儲存到瀏覽器（localStorage，最多 20 筆）、載入、刪除。
- 可匯出 JSON 行程檔。
- 「列印行程」會切換成 A4 列印版（隱藏地圖與操作列，保留統計、站點、電量與補電建議）。
- 右上角「?」有使用說明；地圖可切換一般街道圖／地形圖，並可顯示 33 個示範充電站。

## n⁷ 里程模型

預設值（2024 n⁷ 短程版）：

| 參數 | 值 |
| --- | --- |
| 電池容量 | 57.3 kWh |
| 滿電基準里程 | 280 km（車主實測值；NEDC 438 km 僅供對照） |
| 出發電量 | 90% |
| 保留電量 | 10% |
| 環境氣溫 | 24°C |
| 空調／載重／路況／天候 | 中等／2 人／混合／晴 |

計算方式（`js/engine.js`）：

1. **打折係數**：氣溫（-10～40°C 查表）、空調、載重、行車型態、天候五項相乘。
   - 氣溫以 26°C 為 1.00，低溫與高溫都會打折。
   - 空調 0.91～1.00、載重 0.88～1.00、路況 0.88～1.06、天候 0.92～1.00。
2. **有效滿電里程** = 滿電基準里程 × 打折係數。
3. **實際可用里程** = 有效滿電里程 ×（出發電量 − 保留電量）÷ 100。
4. **單段里程** = 直線距離 × 道路係數（平地 1.26、山區 1.50、高山 1.58）；按「取得道路里程」後改用 OSRM 的實際道路距離。
5. **單段耗能** = 里程 ×（電池容量 ÷ 有效滿電里程）＋ 爬升 × 0.006 kWh/m。
   - 爬升以「目的地海拔 − 出發地海拔」估算，下坡回充**不計**，屬保守估計。
6. **補電建議**：某段抵達電量低於保留電量時，優先找目的地 25 km 內充電站，其次找路段中點 20 km 內充電站；AC 慢充會標示「建議過夜」，並在只有慢充時提醒先到附近的 DC 快充站。

預設值算出來是：有效滿電 **260 km**、實際可用 **208 km**、能耗約 **22.0 kWh/100 km**。

> 這些數字是規劃參考，不是保證。實際能耗受風向、胎壓、坡度、塞車、冷氣設定與右腳影響很大。

## 2026-10-28 新增：我的車、終點預留電量、山下補電智能檢查

- **我的車（電動車分頁）**：新增／編輯／刪除車輛，欄位就是七項——車子型號、電池容量（kWh）、可行駛總里程（km）、一般道路／高速／爬坡（km/kWh）、接頭。行程、可用里程圈與補電點都用選中的車算，並存到瀏覽器（`wildvolt.v1` 的 `ev.vehicles`）。系統會檢查「電池 × 一般道路」跟標示總里程差多少，差 15% 以上會提醒你再確認（例如把 NEDC 當實測填）。
- **終點預留電量（行程分頁）**：不再藏在電動車設定裡，行程面板直接問「終點要留多少電？」（10–50%，快速按鈕 20／30／40%）。終點是高山車宿／露營時自動建議留 30%（過夜用電＋隔天回程），低於建議會在提示裡叫你改。
- **山下補電智能檢查（行程分頁「上山前檢查」卡片）**：終點／過夜點是高海拔（≥600 m）或爬升 ≥350 m 時，系統先算到山下最後一個快充時的電量、以及「預留電量＋上山耗電」在山下該剩多少，再決定要不要補——不論需不需要補都會顯示一張卡片，不只藏在警告裡。
  - `智能建議`（預設）：到不了「預留＋5% 緩衝」就補；或目的地附近同海拔帶沒有該車接頭的 DC 快充、且山下電量不到 85% 時，也建議先補到 85% 再上山。
  - `只在到不了預留電量時補`：舊行為，只有抵達會低於預留才補。
  - `不建議山下補電`：缺電時改走途中／目的地補電。
  - 範例：雲林斗南→隙頂車宿（51.2 km、爬升 1,215 m），90% 出發、留 30% 時，山下 U-Power 嘉義中埔站 78% → 85%（約 5 分鐘），抵達隙頂約 73%；60% 出發時同一站 48% → 85%（約 15 分鐘），抵達也是約 73%。這兩個數字是用 Node 直接跑 `engine.js` 驗算的，不是畫面估值。
- **補電點以目前用車接頭為主**：n⁷ 就是 CCS1／J1772，山下快充、沿線快充、目的地最近充電點都優先找相容站點；25 km 內完全沒有相容站點才退而求其次並警示。接頭不是 n⁷ 的車款（例如 CCS2）會對應自己的接頭。
- **新增據點與範例**：出發地新增「雲林斗南」；車露新增「隙頂停車場（車宿）」（嘉義番路，海拔約 1,250 m，山上無快充）；快速範例新增「雲林→隙頂車宿」（雲林出發、留 30%、山下智能補電）。
- **舊版注意**：電動車分頁原本的「電池容量／滿電基準里程」滑桿已移除，因為它改不到真正算里程的車輛資料（舊版 bug：滑了也沒用，永遠用 n⁷ 短程版算）。舊存檔的車輛若沒有車庫資料，會自動補上預設 n⁷ 短程版。

## 資料來源與免責

- 露營、車露、登山、美食、充電站皆為**人工整理的示範資料**，座標與營業資訊為近似值，請以官方網站、粉絲團、PlugShare／U-Power／EVALUE／iCharging 為準。
- 地圖圖磚：OSM 法國 HOT（一般）、Esri World Topo（地形）。2026-10-29 修復：原本的 tile.openstreetmap.org／tile.opentopomap.org 會回傳 Access blocked 圖磚（HTTP 仍是 200，程式看不出錯），不是本機少檔案，改圖磚來源才解決。
- 國道走法（2026-10-29 新增）：行程面板可選自動／國道一號／國道三號／一般道路，並比較四種走法的里程、時間、耗電與抵達電量；國道走法會列出沿途服務區／休息站快充（國一 7 處、國三 8 處，含中壢、楊梅、泰安、西螺、新營、仁德、寶山、南投、古坑、關廟等新站，另有既有的湖口、關西、西湖、清水、東山），點「在這裡充」即可把該服務區排入充電計畫。國道里程為折線估算（非即時路徑 API），最終以現場路標與 OSRM 實測為準。
- 列印（2026-10-29 新增）：按「列印行程」會印出一張大字行程表（分段里程表＋充電計畫表＋沿途服務區＋提醒），字體 13.5–20pt，適合帶上車紙本對照；螢幕上的小字分段與補電卡列印時不重複印出。
- 多日與回程（2026-10-29 新增）：行程面板可選出遊天數（1–7 天）與「加入回程」（最後回到出發地，回程里程、耗電、補電都會算進總計）；每站旁邊可選「第幾天到達」，沒選的站自動跟著前一站走；下方「分日行程」會按天分組顯示每天去哪、住哪（夜宿點）、補幾次電，列印表裡也有同一張分日彙總表。範例新增「雲林→棚集山 2 日＋回程」（第 1 天丹林車露過夜、第 2 天登棚集山後回雲林）。
- Android 手機安裝（2026-10-29 新增，PWA）：已加 manifest.webmanifest、Service Worker（sw.js）與 192／512 圖示。架站方式：把 wildvolt/ 整個資料夾丟上 GitHub Pages 或 Netlify（拖曳資料夾即可，會給你一個 https 網址），在 Android Chrome 開啟後點 ⋮ →「加到主畫面」或「安裝應用程式」，頂欄出現下載圖示時點它也可直接安裝。注意：完整 PWA 安裝需要 https；只在自家區網用電腦跑 node serve.mjs 再用手機開 http://電腦IP:4173 的話，也可以加到主畫面當捷徑，但 Service Worker 與離線殼不會生效，且每次都要電腦開著伺服器。
- 即時美食：先查 OpenStreetMap Nominatim（地名索引，速度快），查無資料才改用 Overpass API（完整圖徵）。兩者都可能忙碌或受限，失敗時會保留內建資料並顯示提示。
- 實際道路里程：OSRM 公開示範伺服器（`router.project-osrm.org`）。

## 已知限制

- 示範資料不是即時抓取，新增／歇業／遷址都不會自動更新。
- 里程以「站點之間」估算，未考慮同一站點內的移動、繞路或停車位置。
- 爬山行程只計算到登山口，不含步道內的步行時間與體力評估。
- 充電站僅有示範資料，沒有即時可用車位、排隊狀態或費率。
- Nominatim／Overpass／OSRM 都是免費公共服務，偶爾會忙線或限流。
